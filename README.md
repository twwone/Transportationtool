# 交通助理

航空地勤 / 出差旅行用的一站式工具站，Flask + Vanilla JS，iOS 毛玻璃風格 UI，行動裝置優先（393px）。

## 功能

- **捷運（MRT）**：即時到站、月台方向、時刻表查詢。
- **航空資訊看板（TIAS）**：即時航班動態。
- **亞洲航空航班資訊**：讀取共用 Notion OIC 看板（唯讀），只顯示 FD/AK/Z2/D7（AirAsia Group）的航班，卡片式呈現。今天的航班一律顯示（含已完成），只有日期跨到隔天才變成可往回查的歷史資料，可切換查看前一天。可釘選當天負責的航班置頂顯示，釘選狀態用固定同步碼跨裝置同步（每 30 秒更新）、每日自動清空。Notion 查詢只附前 1000 筆內容，後端會補抓其餘航班。點開航班可看「需求與詳情」：Notion 上的完整欄位（Status/DATE/ACFT REG/STA/GATE/ETA/STD/SPCL/GSE/CGO/RMK/ALS）原樣列出、不翻譯不改寫，空值顯示 Empty，CGO/SPCL/GSE/ALS 有實際需求時標紅方便掃視；有附件的航班還能接著看照片、裝載通知單等 Notion 頁面內容與 AI 重點摘要。右上角廣播詞按鈕可瀏覽 Notion 上依機隊代碼／目的地／情境分類好的廣播錄音（MDAC、Hand Carry、Power Bank、Zone 1-3、Final Call 等），點選即播放，畫面右下角常駐迷你播放器，關掉瀏覽面板、切到別的 App 或鎖螢幕都能繼續播（Media Session API），但切到本站其他分頁會整頁重載而中斷播放。資料來源非官方支援管道，格式異動時需另外調整。
- **高鐵優惠監控（/thsr）**：監控早鳥、大學生優惠，某班次優惠「從沒有變成有」就推 Telegram（第一行寫優惠種類、班數與最低折數；訊息下方第一列是「打開高鐵時刻表」「打開任務頁」連結按鈕，第二列「暫停／繼續這個任務」「刪除這個任務」在 Telegram 按一下就生效（網頁或 Telegram 改了狀態，最近 10 則通知的按鈕都會同步更新），由 `/api/thsr/tg-webhook` 接收，只接受設定的聊天室；首次部署後打一次 `/api/thsr/tg-setup?key=THSR_TICK_KEY` 設定回呼），同一班不重複推、被搶光不通知。最多 5 筆任務，條件為起訖站 + 日期 + 發車時段 + 可選最晚抵達 + 可選指定車次（選好起訖站與日期後，表單列出當天全部班次並標出目前有早鳥／大學生優惠的班次與折數，點選即可；只盯選到的那幾班，發車時段自動不適用）；表單可開「加回程」一次建立去程＋回程兩筆任務（回程起訖站自動對調、各自選日期與車次、共用優惠，卡片與通知會標去程／回程）；任務卡片有「編輯」可把條件帶回表單修改（保留暫停狀態與去程／回程標記，儲存後照新條件重新判斷通知）；過了時段自動結束，超過 28 天的日期顯示開賣倒數。由 cron-job.org 每分鐘呼叫 `/api/thsr/tick?key=THSR_TICK_KEY` 查一輪，任務與通知紀錄存 KV；連續失敗 10 輪推故障通知、恢復再推一則。只查得到優惠，一般車廂座位需過驗證碼故不支援。環境變數：`THSR_TICK_KEY`、`TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`。
- **Weight & Balance 貨艙裝載計算（/loadsheet，獨立 app 版 /wb）**：`/wb` 是同一頁、同一份資料的獨立 app 版，有自己的 W&B 名稱與 AirAsia 紅色圖示、沒有返回鍵，可從 Safari「加入主畫面」放到手機桌面（舊網址 /lt 自動轉到 /wb）。介面仿 Airbus Flysmart+ Loadsheet（配色、漸層、框線取自官方 app 的 colorCode.plist 與介面圖檔實測：拉絲金屬底、淺灰標題條、深色欄位群組、選中欄位藍灰、白色按鈕；青色輸入值、黃色帶入值、綠色計算結果、紅色超限）。落地 LDM 航班查詢（預設今天，可往前查、最多往後看到明天，日期顯示為 23OCT2026 格式；點 Notion 圖片可放大檢視，檢視時可雙指／滾輪縮放到 6 倍、放大後單指拖曳移動、點兩下放大或還原），輸入組員行李／Toolbox／轉機行李／垃圾／貨物的艙位與件數重量，加上出發行李總件數與總重，自動建議各艙件數（A321 上限 HOLD1 50／HOLD2 90／HOLD3 90／HOLD4 50 件，填艙順序 3 → 4 → 2 → 1，有貨的艙（任一筆貨物有填件數或重量）不分配行李、改貨物艙位或增刪貨物會自動重算，HOLD2、HOLD3 先各裝 80 件，全部艙都滿了才補到 90；HOLD5 BULK 不分配、塞小件）。每艙重量 = 行李（件數 × 平均重；件數全部分配完時，件數多的艙先用件數 × 平均重，件數最少的那艙改用總重減其他艙吸收誤差（同件數取艙位順序較後的））＋該艙組員／Toolbox／垃圾／貨物，卡片列出完整公式與明細；這幾項只算重量、件數不佔艙位上限，貨物另外不算進該艙超重判斷，可放 HOLD5 BULK 以外的任何一艙（A320 HOLD1／3／4、A321 HOLD1～4，自行選擇），結果與總重合計以橘色標示、只顯示重量；貨物可按「+ ADD CARGO」分批填多種貨，依序編號 Cargo 1、2、3…，每筆各自填艙位、件數、KG，多筆可放不同艙，✕ 可刪除該筆，卡片與總重合計逐筆列出（舊版單筆貨物資料自動轉成第一筆）；每筆貨物只裝一部分時可各自填 LOADED PCS（實際裝的件數，留空代表全裝），下方顯示已裝與未裝的件數和重量（已裝重量 = 件數 × 貨物 KG ÷ PCS 四捨五入到整數，未裝 = 總重 − 已裝，全裝時直接用總重），超過貨物件數會標紅；TOTAL LOAD 總表同步顯示「Cargo loaded 已裝／總件數」與已裝重量，未裝的件數重量以刪除線另列，TOTAL 只加已裝重量；各艙卡片的艙重也改算已裝重量，標籤顯示「Cargo loaded 已裝／總件數 · 重量」；這欄不影響行李件數分配；選 LDM 航班時讀 Notion 的 CGO 欄位，在貨物旁標示「有貨／NIL／未標示 · 航班」，NIL 時貨物欄顯示 NIL 並清空成一筆空白（仍可手動輸入），有貨則不動；轉機行李已含在出發行李內，不重複加重但件數佔上限；轉機行李單獨放一艙（沒混一般行李）時，該艙用轉機實重，其他艙改用扣掉轉機後的平均重，混裝則照平均重算。按 COMPUTE 前會先檢查：特殊項目有數字沒選艙位、選了艙位沒填 KG（轉機行李是件數）、出發行李總件數／總重沒填，會跳出 CHECK INPUT 警示框（FIX 跳到第一個問題／COMPUTE ANYWAY 照樣計算），並在欄位標紅框紅字，填好即時消失。點數字框會跳出 FlySmart 樣式的數字鍵盤彈窗（不叫出系統鍵盤）：第一個數字取代舊值、⌫ 從後面刪、ⓧ 清空、↺ 還原成上一次按 Done 的數字、Next 跳下一格、Done 或點旁邊完成；手機鍵盤不能輸入小數點（電腦實體鍵盤可以），各艙件數按 Done 才重算。同步碼跨裝置同步：開頁先顯示本機資料、雲端有資料再覆蓋，CLEAR 會在雲端留下標記，其他裝置下次開頁也跟著清空。改轉機艙位或件數會自動重算分配（會蓋掉手動改過的各艙件數），改其他特殊項目不重算；換機型時新機型沒有的艙位會被清掉並標紅提醒重選。LDM 沒有續程項目時有按鈕可一鍵清掉上一班的特殊項目。從背景切回來時，跨日或超過 5 分鐘會自動刷新航班清單。LDM 日期以台灣時間計算。航班列表右側顯示抵達狀態：資料來自 Flightradar24（非官方端點，後端快取 60 秒，頁面開著時每 2 分鐘重抓、倒數每 30 秒更新），已落地顯示青色「LANDED 時間 · 多久前」、飛行中顯示綠色「ETA 時間 · in 1h 12m」、尚未起飛顯示「STA 時間 · Dep in …／Not departed」；預計或實際抵達比表定晚 1 分鐘以上時，標籤改為紅色「DELAY 時間」並附晚多久（已落地「Landed +30m」、飛行中「+40m · in 1h 10m」，FR24 沒給 ETA 時用實際起飛時間加表定航程推算、過了 ETA 還沒落地則延誤跟著時間增加；還沒起飛時以延後的起飛時間推算，過了表定起飛還沒飛就以現在當起飛時間估；Notion 備援則比 ETA 與 STA）；依 Notion 的 STA（含「前一天」）對到 FR24 最接近的抵達 TPE 航段（相差 6 小時內）；FR24 抓不到時改用 Notion 的 ETA 欄位以橘色顯示（格式錯誤的值不顯示）。標題列日期左邊有刷新鍵，按下會略過快取立刻重抓 FR24（同一班號 10 秒內只真的抓一次，避免連按被擋），抓完前圖示轉圈。選航班後由 Gemini 讀 Notion 附件，辨識落地後留機續飛的組員行李／Toolbox／轉機行李／垃圾（件數、重量、艙位），每項附 LDM 原文供核對；機型不再用航班號猜（同航班可能換機），改由 Gemini 讀 LDM 航班行的機號與座位配置判斷（例如 `FD230/24.HSBBX.Y180` → 180 座 A320、186 座 A320neo（艙位設定同 A320，只在標題標示 neo），230 座以上 A321，原文直接寫 A320／A321 時以原文為準），航班列表也顯示 Notion 的機號，航班代碼方塊用航空公司所屬國國旗配色（FD 泰國、AK 馬來西亞、Z2 菲律賓，不代表機型）；LDM 看不出機型時標示 Type unknown、不自動切換，請手動選 A320／A321。按「套用」才會寫入特殊項目並切換到 LDM 判斷出的機型（換機型時會照新機型重新分配艙位）；LDM 尚未上傳的航班不快取，之後可重新辨識；辨識結果與 AI 摘要的快取跟著附件內容走，附件重傳就會重新辨識。附件超過 8 個時，LDM 辨識只讀最後 8 個、AI 摘要只讀前 8 個。電腦版：寬 768px 以上改兩欄（左 ARRIVAL LDM／右 輸入與結果，限寬 920px），1280px 以上改三欄（LDM／SPECIAL LOAD 與 DEPARTURE BAGS／計算結果，限寬 1360px）；LDM 欄與結果欄固定在畫面上、內容太長在欄內自己捲動，可以一邊看 LDM 附件一邊填數字，按 COMPUTE 不用往下捲就看得到分配；機型切換改成置中的分段鈕，圖片放大視窗加寬到 900px；手機版排版不變。
- **班表（Schedule）**：個人班表週檢視。月份標題下有統計卡：本月已上班天數 / 總上班天數、已上時數 / 總時數（依班別代碼的上下班時間計算，下班早於上班視為跨夜；代碼查不到時間的不計時數）、進度條，以及剩餘上班、上課、休假天數（有請假時另列病假、事假天數，不算進上班天數與時數）；「已上」算到今天為止（含今天），過去月份全算已上、未來月份全算未上。點日期格子可改班別，快速按鈕有 @ 休假、E 上課、SL 病假、PL 事假，病假、事假在格子上分別以橘色、紫色標示，跟其他調整一樣用同步碼跨裝置同步。電腦版（寬度 768px 以上）內容置中限寬 920px，格子改固定高度、字放大靠左排，滑鼠移上去有外框提示；手機版維持原樣。
- **天氣（Weather）**：METAR 與一般天氣查詢。
- **即時翻譯（Translate）**：首頁浮動工具，開啟後全螢幕顯示，與旅客即時溝通用。文字/語音輸入、19 種固定語言、單向或面對面對話模式，由 Gemini Flash-Lite 提供翻譯，語音輸入直接送音訊給 Gemini（不經瀏覽器語音辨識）。畫面只顯示最新一則翻譯結果（不累積對話紀錄），大字體顯示方便旅客閱讀，內容過長會自動縮小字體塞進畫面、不用滑動；播放語音與複製文字為結果框右上角小按鈕，不佔用文字顯示空間，也能一鍵翻轉 180 度給旅客看不用轉手機（可切回不翻轉）。
- **簽證指南（Visa Guide）**：見下方。
- **備忘錄（Memo）**：待辦、她的喜好、約會計畫，加上「金錢」分頁：月曆式記錄兩人每天吃飯、互相買東西花的錢。每筆填項目、金額、誰付的（我付／她付）、日期；月曆格子顯示當天合計金額，藍點代表我付、紅點代表她付，上方統計本月我付、她付、合計與誰多付多少，點日期看當天明細，點明細可修改或刪除。月曆上方有搜尋框，輸入關鍵字（空白分隔可多個）會跨所有月份找出符合的紀錄，依月份分組列出，並統計這些紀錄的我付、她付、合計與筆數，點結果一樣能修改，按清除鈕回到月曆。編輯面板從畫面上緣滑下，避免 iOS 鍵盤遮住輸入框。電腦版（寬度 768px 以上）整頁置中限寬 920px，金錢分頁改成左邊月曆、右邊當天明細兩欄，編輯面板改為置中卡片；手機版維持原樣。資料存在雲端 KV，跨裝置共用；舊版頁面存檔時沒帶金錢資料會沿用雲端既有紀錄，不會被清空。
- **私人收藏庫（/v）**：PIN 鎖的影片收藏，可手動貼網址或用 Bookmarklet 帶參數收藏。missav 網址會自動拆出番號、判斷無碼並套上封面（`fourhoi.com/{slug}/cover-n.jpg`），卡片以番號為主、下方顯示清掉網站後綴的標題；其他網站會抓網頁的 og 標題與預覽圖。missav 有 Cloudflare 擋伺服器抓不到標題，所以手動貼 missav 網址（沒經過 Bookmarklet 帶標題）時改用番號查：先查 r18.dev（一般有碼番號，存日文原標題，英文標題另存供搜尋），查不到再查 javdb 搜尋頁（FC2、HEYZO 等）；Bookmarklet 帶進來的標題照舊不動。舊的無標題收藏在解鎖後背景自動補（`/api/v/backfill`，一次 8 筆、補到沒有為止，完成跳「已補上 N 部標題」），查不到的番號記下時間，3 天後才再試。missav 收藏只存路徑，打開時用設定裡的網域組網址，網站換網域時點標題旁齒輪改一次即可；換網域或帶 `dm` 前綴的同一部片會判定為重複。上方搜尋框可即時篩選番號、標題、網站、加入者或「無碼」，空白分隔多個關鍵字要全部符合，比對時不分大小寫、忽略連字號（打 ssis123 找得到 SSIS-123），顯示找到幾部，按 ✕ 或 Esc 清除，電腦版按 / 或 Cmd/Ctrl+K 直接跳到搜尋框，上鎖時一併清掉搜尋字。PIN 解鎖後記在該裝置，按鎖頭才清掉；同一 IP 連續輸錯 8 次鎖 15 分鐘。已移除首頁管理員免密碼入口（管理員 PIN 寫在前端，等於公開）。舊資料第一次載入時自動補齊。電腦版置中限寬 920px、彈窗改置中卡片。資料存在雲端 KV。

## 簽證指南（Visa Guide）

查詢「任一國籍護照 → 目的地」的簽證需求，不再侷限台灣護照。

- **選擇旅客國籍**：支援約 199 本護照，於全螢幕選單挑選國籍。
- **搜尋 / 篩選目的地**：依 免簽 / 落地簽 / 電子簽・授權 / 需簽證 快速過濾。
- **資料來源**：
  - 各國籍簽證矩陣採用 [passport-index-dataset](https://github.com/ilyankou/passport-index-dataset)（社群整理，僅供大方向參考）。
  - 台灣護照維持手動整理之詳細卡片（所需文件、實用提醒、注意事項、官方連結）。
- 實際入境文件與最新規定，一律以各國官方移民機關或外交部領事事務局為準。

## 開發

```bash
python3 -m flask --app app run --port 5001
```

部署於 Vercel（見 `vercel.json`）。

`/loadsheet` 的樣式與程式拆在 `static/loadsheet.css`、`static/loadsheet.js`；模板用 `asset_ver()` 在網址後加內容雜湊（`?v=`），檔案一改網址就變，不會被 Service Worker 的舊快取卡住。
