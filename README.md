# 交通助理

航空地勤 / 出差旅行用的一站式工具站，Flask + Vanilla JS，iOS 毛玻璃風格 UI，行動裝置優先（393px）。

## 功能

- **捷運（MRT）**：即時到站、月台方向、時刻表查詢。
- **航空資訊看板（TIAS）**：即時航班動態。
- **亞洲航空航班資訊**：讀取共用 Notion OIC 看板（唯讀），只顯示 FD/AK/Z2/D7（AirAsia Group）的航班，卡片式呈現。今天的航班一律顯示（含已完成），只有日期跨到隔天才變成可往回查的歷史資料，可切換查看前一天。可釘選當天負責的航班置頂顯示，釘選狀態跨裝置同步、每日自動清空。點開航班可看「需求與詳情」：Notion 上的完整欄位（Status/DATE/ACFT REG/STA/GATE/ETA/STD/SPCL/GSE/CGO/RMK/ALS）原樣列出、不翻譯不改寫，空值顯示 Empty，CGO/SPCL/GSE/ALS 有實際需求時標紅方便掃視；有附件的航班還能接著看照片、裝載通知單等 Notion 頁面內容與 AI 重點摘要。右上角廣播詞按鈕可瀏覽 Notion 上依機隊代碼／目的地／情境分類好的廣播錄音（MDAC、Hand Carry、Power Bank、Zone 1-3、Final Call 等），點選即播放，畫面右下角常駐迷你播放器，關掉瀏覽面板、切到別的 App 或鎖螢幕都能繼續播（Media Session API），但切到本站其他分頁會整頁重載而中斷播放。資料來源非官方支援管道，格式異動時需另外調整。
- **高鐵優惠監控（/thsr）**：監控早鳥、大學生優惠，某班次優惠「從沒有變成有」就推 Telegram（第一行寫優惠種類、班數與最低折數；訊息下方第一列是「打開高鐵時刻表」「打開任務頁」連結按鈕，第二列「暫停／繼續這個任務」「刪除這個任務」在 Telegram 按一下就生效（網頁或 Telegram 改了狀態，最近 10 則通知的按鈕都會同步更新），由 `/api/thsr/tg-webhook` 接收，只接受設定的聊天室；首次部署後打一次 `/api/thsr/tg-setup?key=THSR_TICK_KEY` 設定回呼），同一班不重複推、被搶光不通知。最多 5 筆任務，條件為起訖站 + 日期 + 發車時段 + 可選最晚抵達 + 可選指定車次（選好起訖站與日期後，表單列出當天全部班次並標出目前有早鳥／大學生優惠的班次與折數，點選即可；只盯選到的那幾班，發車時段自動不適用）；表單可開「加回程」一次建立去程＋回程兩筆任務（回程起訖站自動對調、各自選日期與車次、共用優惠，卡片與通知會標去程／回程）；任務卡片有「編輯」可把條件帶回表單修改（保留暫停狀態與去程／回程標記，儲存後照新條件重新判斷通知）；過了時段自動結束，超過 28 天的日期顯示開賣倒數。由 cron-job.org 每分鐘呼叫 `/api/thsr/tick?key=THSR_TICK_KEY` 查一輪，任務與通知紀錄存 KV；連續失敗 10 輪推故障通知、恢復再推一則。只查得到優惠，一般車廂座位需過驗證碼故不支援。環境變數：`THSR_TICK_KEY`、`TELEGRAM_BOT_TOKEN`、`TELEGRAM_CHAT_ID`。
- **Weight & Balance 貨艙裝載計算（/loadsheet，獨立 app 版 /wb）**：`/wb` 是同一頁、同一份資料的獨立 app 版，有自己的 W&B 名稱與 AirAsia 紅色圖示、沒有返回鍵，可從 Safari「加入主畫面」放到手機桌面（舊網址 /lt 自動轉到 /wb）。介面仿 Airbus Flysmart+ Loadsheet（配色、漸層、框線取自官方 app 的 colorCode.plist 與介面圖檔實測：拉絲金屬底、淺灰標題條、深色欄位群組、選中欄位藍灰、白色按鈕；青色輸入值、黃色帶入值、綠色計算結果、紅色超限）。落地 LDM 航班查詢（預設今天，可往前查、最多往後看到明天，日期顯示為 23OCT2026 格式；點 Notion 圖片可放大檢視），輸入組員行李／Toolbox／轉機行李／垃圾／貨物的艙位與件數重量，加上出發行李總件數與總重，自動建議各艙件數（A321 上限 HOLD1 50／HOLD2 90／HOLD3 90／HOLD4 50 件，填艙順序 3 → 4 → 2 → 1，HOLD2、HOLD3 先各裝 80 件，全部艙都滿了才補到 90；HOLD5 BULK 不分配、塞小件）。每艙重量 = 行李（件數 × 平均重；件數全部分配完時最後一艙改用總重減其他艙吸收誤差）＋該艙組員／Toolbox／垃圾／貨物，卡片列出完整公式與明細；這幾項只算重量、件數不佔艙位上限，貨物另外不算進該艙超重判斷，且只能放 A320 HOLD3／A321 HOLD2、HOLD3（自行選擇），結果與總重合計以橘色標示、只顯示重量；選 LDM 航班時讀 Notion 的 CGO 欄位，在貨物旁標示「有貨／NIL／未標示 · 航班」，NIL 時貨物欄顯示 NIL 並清空（仍可手動輸入），有貨則不動；轉機行李已含在出發行李內，不重複加重但件數佔上限；轉機行李單獨放一艙（沒混一般行李）時，該艙用轉機實重，其他艙改用扣掉轉機後的平均重，混裝則照平均重算。點數字框會跳出 FlySmart 樣式的數字鍵盤彈窗（不叫出系統鍵盤）：第一個數字取代舊值、⌫ 從後面刪、ⓧ 清空、↺ 還原成上一次按 Done 的數字、Next 跳下一格、Done 或點旁邊完成；手機鍵盤不能輸入小數點（電腦實體鍵盤可以），各艙件數按 Done 才重算。同步碼跨裝置同步：開頁先顯示本機資料、雲端有資料再覆蓋，清除會一併清空雲端。LDM 日期以台灣時間計算。選航班後由 Gemini 讀 Notion 附件，辨識落地後留機續飛的組員行李／Toolbox／轉機行李／垃圾（件數、重量、艙位），每項附 LDM 原文供核對，按「套用」才會寫入特殊項目並切換機型；LDM 尚未上傳的航班不快取，之後可重新辨識。
- **班表（Schedule）**：個人班表週檢視。
- **天氣（Weather）**：METAR 與一般天氣查詢。
- **飲食（Diet）**：飲食紀錄與 AI 食物分析，跨裝置同步。
- **即時翻譯（Translate）**：首頁浮動工具，開啟後全螢幕顯示，與旅客即時溝通用。文字/語音輸入、19 種固定語言、單向或面對面對話模式，由 Gemini Flash-Lite 提供翻譯，語音輸入直接送音訊給 Gemini（不經瀏覽器語音辨識）。畫面只顯示最新一則翻譯結果（不累積對話紀錄），大字體顯示方便旅客閱讀，內容過長會自動縮小字體塞進畫面、不用滑動；播放語音與複製文字為結果框右上角小按鈕，不佔用文字顯示空間，也能一鍵翻轉 180 度給旅客看不用轉手機（可切回不翻轉）。
- **簽證指南（Visa Guide）**：見下方。
- **備忘（Memo）／設定（Settings）／分享（Share）** 等輔助功能。

## 簽證指南（Visa Guide）

查詢「任一國籍護照 → 目的地」的簽證需求，不再侷限台灣護照。

- **選擇旅客國籍**：支援約 199 本護照，於全螢幕選單挑選國籍。
- **搜尋 / 篩選目的地**：依 免簽 / 落地簽 / 電子簽・授權 / 需簽證 快速過濾。
- **資料來源**：
  - 各國籍簽證矩陣採用 [passport-index-dataset](https://github.com/ilyankou/passport-index-dataset)（社群整理，僅供大方向參考）。
  - 台灣護照維持手動整理之詳細卡片（所需文件、實用提醒、注意事項、官方連結）。
- 實際入境文件與最新規定，一律以各國官方移民機關或外交部領事事務局為準。
