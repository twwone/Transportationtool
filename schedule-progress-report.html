三、根本原因分析

TDX 交通部資料平台在 basic（免費）層的航空資料僅提供：

  • FIDS 即時起降資料（今日航班）
  • 機場 / 航空公司靜態基本資料

「定期航班班表（General Schedule）」資料在 basic 層不存在，可能需要申請進階（advanced/付費）層，或與交通部另行洽詢。

四、可行的替代方案

方案可行性說明
TDX advanced（付費）層 未驗證 需升級帳號，月費視用量而定；端點可能存在
AviationStack API 部分可行 免費層 500 次/月，有 routes 資料，但 future schedule 需付費
AeroDataBox API 部分可行 RapidAPI 上的航班計畫 API，有免費配額，含 days-of-operation
手動班表（AirAsia 官網截取） 人工維護 直接從 AirAsia 官網查 TPE 的每日班次寫入設定檔，每季更新一次
FIDS 累積統計 需改架構 每天快取今日 FIDS 資料，7 天後可推算每週分布；需持久化儲存
移除週班表功能 立即可行 從首頁移除卡片，等待資料來源有解法再啟動
